AmazeMe

Sistema integral para seleccion guiada de regalos, gestion de usuarios y motor de fidelizacion mediante recompensas.

ASP.NET Core Entity Framework Core SQL Server Bootstrap 5.3
El Concepto

Eliminando la friccion al elegir regalos

El objetivo principal de AmazeMe es transformar la incertidumbre del comprador en una experiencia agil. En lugar de navegar cientos de categorias confusas, la plataforma toma las riendas del proceso guiando al cliente con preguntas simples para dar con la recomendacion adecuada.

Diseñado como un modelo de comercio inteligente que beneficia tanto al cliente con descuentos como al negocio con compras recurrentes.

Experiencia de Usuario

Encuesta interactiva paso a paso

Se diseño una interfaz minimalista donde solo se muestra una pregunta a la vez para mantener el foco del usuario. Cuenta con soporte de seleccion visual y barra de progreso calculada en tiempo real.

  • Avance dinamico sin recarga molesta de pagina.
  • Seleccion clara entre familiares, amigos y companeros.
  • Captura controlada de parametros para el algoritmo de sugerencias.
Seguridad & Datos

Autenticacion y manejo de errores

Tanto el registro como el inicio de sesion fueron estructurados con comprobacion de campos y encriptado robusto de contrasenas mediante BCrypt.

Contrasenas

Proteccion criptografica antes de llegar a la base de datos.

Retroalimentacion

Mensajes de error visuales que guian al usuario sin confusiones.

Retencion

Amazings: Moneda de recompensa

El sistema integra un modulo de balance de puntos donde cada transaccion registra puntos ganados y puntos gastados en base de datos, incentivando compras futuras y aumentando el valor de vida del cliente.

Sistema de Lealtad Integrado
Conversion de puntos en fondos de descuento listos para usar.
